# Lexical Analyzer and Socket Server

These are my Java labs from 3 courses of my B.Sc. in Computer Science and Engineering at BRAC University. I did them in 2021.

## What is inside

| Folder | Course | What it does |
|---|---|---|
| `01-compiler-lexical-analyzer` | CSE420 Compiler Design | A lexical analyzer. It reads a small program and lists the keywords, identifiers, math and logical operators, numbers and other symbols |
| `02-compiler-lab3` | CSE420 Compiler Design | Matches tokens with regular expressions |
| `03-compiler-lab4` | CSE420 Compiler Design | Reads Java like code and prints every method with its parameters and return type |
| `04-socket-programming` | CSE421 Computer Networks | TCP client and server programs with Java sockets, with a calculator server and a multithreaded server |
| `05-os-threads` | CSE321 Operating Systems | A Java threads task |

## How to run

Step 1: Install Java 8 or newer.

Step 2: Go to a folder and run `javac *.java`.

Step 3: Run `java <ClassWithMain>`. For the socket tasks, start `Server` first and then `Client`.

The lexical analyzer reads the input from a fixed Windows path, so change it before running.
